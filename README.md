# Что? Где? Когда? · Школьный клуб

Прототип пульта ведущего для школьной игры (9–11 классы). Статический сайт: `index.html`, `style.css`, `app.js`, `audio.js`.

- Вопросы — `questions.json`, пакеты: «Наша база» (21 вопрос клуба) и сгенерированные для 9, 10, 11 классов (по 24). Типы: `normal`, `image` (+ `image`), `blitz` (+ `items` из трёх вопросов), `blackbox`; `opponent` — «Против знатоков играет …», `hint` — подсказка ведущему.
- Сыгранные вопросы запоминаются в браузере и не повторяются в следующих играх (кнопка «Сбросить историю вопросов»).
- Досрочный ответ: если неверно — штраф −1 знатокам и очко телезрителям (или только очко телезрителям — настраивается).
- Список сгенерированных вопросов с ответами — `questions-generated.md`.
- Свою базу в том же формате можно загрузить на экране «Новая игра» → «Загрузить свою базу (JSON)».
- Все звуки синтезируются в браузере (Web Audio API), эмблема и фоны — оригинальные. Музыка, логотип и видео телепередачи не используются.

Клавиши: Пробел — старт/пауза, D — досрочный ответ, R — сброс, Enter — показать ответ, 1 (или +) — верно / очко знатокам, 2 (или −) — неверно / очко телезрителям, H — подсказка, N — следующий вопрос блица, S — крутить волчок, F — во весь экран, M — звук.
